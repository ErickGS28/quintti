# 0001. Name: Quintti

Status: Accepted

## Context

The name Quintti was chosen in an earlier iteration of the project, which explored a different product. It comes from the Quechua *qinti*, hummingbird. A spelling with a single *t* was avoided because it was already registered by something else. The product has since changed focus (a shared treasury for residential buildings), and the logo and palette are being redone.

## Decision

Keep the name **Quintti**. Visual identity (logo and colors) is pending and is documented separately once defined.

## Consequences

- The repository is named `quintti`.
- Availability of the domain, social handles and trademark has not been checked for the new product and remains to be verified.
- No design document exists yet. The interface uses centralized neutral tokens until the identity arrives.
